Neon Salvage is a 2D canvas arcade game: you pilot a salvage skiff through the debris field of a dying star, hauling cargo pods while neon rocks close in. Chain pod pickups within 3 seconds to build a score multiplier up to ×8, grab the rare cyan rich pods before they blink out, and spend your pulse-blast charges to split the big rocks — three hull hits and the star claims another. Play with A/D + W/S or the arrow keys, Space for the pulse blast, or hold the mouse button to thrust toward the pointer.

## Run it
```sh
node serve.ts   # then open http://localhost:8080
```
